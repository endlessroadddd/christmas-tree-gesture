# 🎄 Gesture Christmas Tree 3D（手势控制点阵圣诞树）

一个基于 **Canvas 2D + MediaPipe Hands** 的 9:16 互动点阵圣诞树网页项目：支持摄像头隔空画圈控制圣诞树聚散、本地照片存入浏览器并在圣诞树聚拢至剩 1/3 后显现，以及捏合放大与左滑切图。

---

## ✨ 两个版本（支持一键互切）

1. **树内嵌图版（`video_style_embedded.html`）**
   - **点阵树与小麋鹿**：五层枝叶轮廓、彩色螺旋灯带、发光顶星、地面同心光环与礼物盒，中央配有透明素材驱动、四腿分步摆动的白色点阵小麋鹿；树体与彩灯同步慢转（约 32 秒一圈）。
   - **照片延迟嵌进树中**：添加图片后不会立刻显示，而是等到整棵圣诞树聚合到**还剩 1/3（已出现 2/3）**之后，以圆角微光挂饰形态嵌在旋转树体内部（前排粒子和彩带会在照片前方形成层次遮挡）。
   - **捏住弹出 & 左滑切换**：拇指与食指捏住，当前照片从树内平滑弹出放大；保持捏住向画面左侧滑动约 `9.5%` 宽度切换下一张（支持滞回防抖），松开收回树内。无摄像头也可点右上角 **「🤏 捏住预览」** 体验。

2. **浮卡版（`video_style.html`）**
   - 照片在树聚合至剩 1/3 后以金框拍立得卡片环绕树身漂浮，同样支持捏合放大与左滑切换。
   - 两个版本共用同一份浏览器本地图片库，右上角可随时一键切换。

## 🎮 操作说明

### 🖐️ 摄像头手势
点击 **「开启摄像头」** 并允许浏览器权限：
- **顺时针画圈（镜像视角）**：光环自树底往上移动，粒子逐层聚成树；聚合到还剩 1/3 时照片出现。
- **逆时针画圈（镜像视角）**：从树顶往下逐圈消散；降到 2/3 以下时照片自动隐藏。
- **捏住（🤏）**：打开 / 从树中弹出当前照片。
- **捏住并向左滑**：切换下一张照片（单独甩手不会误触发）。
- **松开**：关闭照片 / 收回树中。

### 🖼️ 本地图片存储
- 点击 **「添加图片」** 支持批量选择 **JPG / PNG / WebP**（最多 30 张，单张不超过 12 MB）。
- 图片在浏览器端缩放后保存于当前设备浏览器的 `IndexedDB`，刷新不丢失，不会上传服务器。
- 点击 **「管理图片」** 可切换当前照片或删除已保存图片。

> 首次开启摄像头需联网从 `jsDelivr` 加载 MediaPipe Hands 模型；摄像头画面仅在本地浏览器处理。

## 🚀 本地运行与测试

由于浏览器摄像头权限限制，请通过本地静态服务器访问：

```bash
python3 -m http.server 8000
```

或：

```bash
npx http-server .
```

浏览器打开：
- 树内嵌图版：`http://127.0.0.1:8000/video_style_embedded.html`
- 浮卡版：`http://127.0.0.1:8000/video_style.html`

### 运行手势单元测试

```bash
node --test gesture_motion.test.js
```
